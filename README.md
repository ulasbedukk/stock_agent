# Stock Analysis Agent

This is a small AI-powered tool that provides real-time stock prices and gives a short comment on whether the current price seems reasonable. It is designed to help investors save time when checking stocks.

## How it works
Run the script, then enter the ticker symbol of the stock you would like to check (e.g. AAPL). The agent fetches the real-time price and asks Claude to provide a short, professional comment on the valuation.

## Technologies used
- Python
- yfinance
- Anthropic API

## How to run it
Run the following command in the terminal:

python stock_agent_v2.py
